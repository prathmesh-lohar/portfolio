Project Overview

This is the official college website of V.D.F School of Engineering and Technology (Latur). Designed and developed from scratch to fulfill the institution's digital communication needs.

The platform empowers the college administration to manage dynamic content without touching code. Using a secure admin dashboard, administrators can create and publish new pages, post news and official announcements, manage media galleries, and track real-time unique website visitors.

For the front-end, semantic HTML5, CSS3, and Bootstrap were implemented to guarantee complete mobile responsiveness and fast load times. The backend is powered by Django (Python), leveraging robust database modeling and flexible database client libraries.

For production deployment, an AWS EC2 Ubuntu cloud instance configured with Apache2 and Cloudflare was deployed for high availability, security, and caching.

Key Features

  1. 1) Dynamic Page Builder: Create and publish new custom pages through a rich-text editor conforming to site templates without coding.
  2. 2) Automated News & Announcements: End-to-end automated news workflow allowing staff to broadcast announcements instantly.
  3. 3) Multi-Format Import & Export: Admin can import and export tabular student and course data into .excel, .word, .pdf, .json, and .html formats.
  4. 4) Real-Time Visitor Tracking: Built-in analytics engine to track and display unique visitors and hit statistics.
  5. 5) Dynamic Gallery & Media Manager: Easy-to-use multimedia upload manager for campus events, fests, and achievements.
