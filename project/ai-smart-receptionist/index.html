Project Overview

The AI Based Smart Receptionist is an autonomous software agent designed to handle receptionist and front-desk responsibilities for enterprises, academic institutions, and organizations like MSBECL.

The system listens to natural human voice queries through audio input devices, tokenizes and extracts intent using Natural Language Toolkit (NLTK), feeds intent representations through a neural network built with PyTorch, and synthesizes clear vocal feedback via gTTS (Google Text-to-Speech).

Beyond static responses, the AI dynamically extracts real-time information by querying APIs and parsing web data sources (such as Wikipedia knowledge integration) to answer unexpected domain and informational queries.

Developed as a comprehensive final year engineering initiative by Prathmesh Lohar, Aniket Madhurkar, and Kedar Tandale under the guidance of Prof. D.V. Biradar.
