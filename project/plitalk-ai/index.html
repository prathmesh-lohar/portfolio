Project Overview

Plitalk AI is an enterprise-grade, real-time conversational AI speech tutoring and mock interview coaching web application. Built to solve the critical gap between passive language learning and real-world spoken fluency, Plitalk AI enables learners, job seekers, and ESL students to conduct natural, sub-second spoken conversations with an AI tutor that analyzes pronunciation, grammar, and fluency in real time.

Unlike typical chatbot interfaces that rely on text inputs, Plitalk AI provides an immersive bidirectional streaming audio pipeline. Users converse freely via microphone or camera, receive instantaneous conversational audio playback from a realistic neural voice, and view dynamic waveform visualizers that bring the digital mentor to life.

The platform includes an AI Interview Preparation Hub featuring scripted single-persona and panel interview simulations with countdown timers, question-by-question spoken answers, automatic Whisper transcription, and comprehensive post-session scoring reports with actionable advice.

System Architecture & Technical Innovations

The architecture of Plitalk AI separates heavy AI inference and real-time streaming into an optimized asynchronous micro-pipeline:

  • Sub-Second Conversational Loop: Integrated with Groq LPU hardware accelerators running Llama 3 models, delivering instantaneous token generation (~300 tokens/sec) that makes conversational turn-taking feel indistinguishable from human dialogue.
  • Real-Time Bidirectional WebSockets: Orchestrated with Django Channels and Daphne ASGI, enabling binary audio streaming, state synchronization, and live conversation turns without HTTP polling overhead.
  • Speech-to-Text (STT) Processing: Employs Groq Whisper-large-v3 and Deepgram Nova for accurate phoneme capture, noise tolerance, and punctuated transcriptions across multiple accents and speaking speeds.
  • Resilient Cascading Fallback TTS: Implements a resilient 4-tier neural text-to-speech hierarchy (Microsoft Edge TTS → Google gTTS → Groq TTS → Piper ONNX local), ensuring zero speech playback interruption even during network volatility.
  • Modern Frontend & State Flow: Built using Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, and Framer Motion for 60fps micro-interactions, responsive sidebars, and audio waveform canvases.
  • Secure Gated Authentication: Powered by Django REST Framework (DRF) with SimpleJWT, incorporating token rotation, approval-based account gating, and role-based access control (Admin / Teacher / Student).

Key Features & Modules

  1. 1) Talk AI Multi-Mode Practice: Seamlessly switch between Voice Chat (pure voice interaction with animated waveform), Video Chat (avatar-assisted visual engagement), and Text Chat modes with custom topic selection (Daily Casual Talk, Job Scenarios, Academic English, and IELTS Speaking).
  2. 2) AI Interview Hub & Session Runner: Full-featured mock interview suite supporting customizable roles (Software Engineer, Nurse, Business Analyst, etc.), experience tiers (Entry, Mid, Senior, Lead), live question countdown timers, and spoken audio submission.
  3. 3) Automated LLM Post-Session Scoring Reports: Comprehensive feedback reports featuring overall score (0–100), grammatical accuracy, vocabulary richness, pacing analysis, and per-question coaching recommendations with better phrasing suggestions.
  4. 4) Structured Video Learning Studio: Categorized curriculum tutorials with lesson progress tracking, completion badges, and targeted pronunciation drills.
  5. 5) Administrator Management Panel: Dedicated studio for curriculum authors to create interview modules, script multi-turn question flows, set time limits, approve registered users, and track real-time LLM token consumption and cost analytics.
  6. 6) Responsive & Accessibility-Centric UI: Engineered with responsive drawer navigation, dark/light adaptive accents, and WCAG-compliant color contrast.
