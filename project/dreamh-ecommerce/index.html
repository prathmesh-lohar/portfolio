Project Overview

DreamH is a complete online shopping website developed as a final year diploma capstone project in 2020. It provides end-to-end e-commerce capabilities from item discovery to delivery tracking.

The platform includes dynamic inventory and catalog management through an administrative interface, allowing store managers to create product listings, manage image assets, define pricing, and group products into structured categories.

Customers can easily explore products, specify shipping details, place orders, and trace their order progress in real-time by submitting their order ID and registered mobile number.

The solution uses Django (Python) for server-side logic and database persistence, Bootstrap for responsive layout structures, and is hosted on PythonAnywhere using Linux CLI automation.

Key Features

  1. 1) Dynamic Content & Catalog CMS: Add, update, and manage inventory dynamically via an admin control panel.
  2. 2) Hierarchical Categorization: Systematically organized departments and subcategories for quick browsing.
  3. 3) Intuitive Order Placement: Simple form-based order entry with validation for required shipping fields.
  4. 4) Real-Time Order Tracking: Track parcels using mobile number and unique order ID.
  5. 5) Fully Responsive Front-End: Adaptive layouts designed for smartphone, tablet, and desktop viewports.
