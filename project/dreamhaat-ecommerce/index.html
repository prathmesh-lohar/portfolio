Project Overview

DreamHaat is a modern e-commerce web application engineered to offer a seamless shopping experience for customers purchasing certified organic food products, natural flours, and wood cold-pressed oils.

Equipped with an intuitive admin dashboard, store operators can effortlessly manage item inventories, update pricing, organize catalogs into categories, and track customer fulfillments without requiring technical expertise.

The customer journey is designed for simplicity: buyers can navigate categorized items, submit orders with essential contact details, and immediately receive an order identifier. Customers can return at any time to verify the delivery status using just their phone number and order ID.

Developed using Python with the Django Framework, backed by Django ORM, and styled with Bootstrap for full cross-device compatibility.

Key Features

  1. 1) Dynamic Product & Inventory CMS: Create, update, toggle availability, or archive products with real-time storefront reflection.
  2. 2) Category-Driven Architecture: Systematic catalog filtering for organic oils, grains, spices, and health supplements.
  3. 3) Seamless Direct Checkout: Low-friction order completion without forced registration hurdles.
  4. 4) Transparent Order Tracking: Track order progress from packing to transit using mobile number and order ID verification.
  5. 5) Mobile Optimized Storefront: Fluid, responsive layout optimized for quick mobile transactions.
