Project Overview

BookMyBlouse (bookmyblouse.com) is an on-demand, digital-first bespoke tailoring and fashion e-commerce platform. It solves the traditional hassle of offline boutique visits by allowing customers across India to design, customize, and order perfect-fit blouses from the comfort of their home with a free re-stitch guarantee.

The frontend is crafted using Next.js 16 (App Router), React 19, TypeScript, and Tailwind CSS v4. It delivers instant page rendering, mobile-first responsive bottom navigation, and full Progressive Web App (PWA) offline caching with installability on Android and iOS devices.

The robust backend architecture is built with Python & Django 5.1+ powered by Django REST Framework (DRF). It features stateless authentication using JWT (SimpleJWT) and Google OAuth, comprehensive measurement profile storage, automated stage-by-stage order processing, and secure online transaction processing via the Razorpay SDK.

An integrated administrative management portal enables operations staff, master tailors, and dispatch handlers to update stitching milestones, verify uploaded design sketches, manage fabric inventories, and send real-time order tracking notifications.

Key Features

  1. 1) 200+ Design Catalog & Custom Design Upload: Explore extensive catalogs of bridal, traditional, boat-neck, V-neck, and zari work blouses, or upload custom design inspirations with specific styling notes.
  2. 2) Guided Measurement & Profile Engine: Interactive step-by-step measurement recorder with visual guides, storing reusable size profiles for quick repeat orders.
  3. 3) Live Stage-by-Stage Order Tracker: End-to-end transparent progress tracking across Fabric Confirmation → Pattern Cutting → Tailoring → Quality Inspection → Dispatched → Delivered.
  4. 4) Razorpay Payment Gateway Integration: Secure checkout supporting UPI, Credit/Debit cards, Net Banking, and digital wallets with automated payment status webhooks.
  5. 5) PWA & Mobile-First Experience: App-like experience with service workers, custom install prompt, bottom navigation bar, and instant mobile responsiveness.
  6. 6) Operations & Tailoring Admin Dashboard: Dedicated internal interface for order assignment, measurement review, and customer support management.
