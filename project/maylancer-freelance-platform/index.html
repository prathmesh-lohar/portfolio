Project Overview

MayLancer is an online freelancing platform built to empower both organizations seeking skilled talent and professionals looking for freelance contracts. The system supports full registration, authentication, role-based workflows, and interactive engagement.

Clients can publish detailed job postings specifying skills, budgets, and timelines, while freelancers can browse categorized openings, apply with personalized proposals, and curate their professional profiles.

Administrators can oversee content, moderate job postings, and handle dispute reviews via a unified backend dashboard. Visitors can test out features using trial credentials directly on the hosted deployment.

Built from the ground up using Django (Python), Bootstrap, and hosted on PythonAnywhere using automated Linux deployment environments.

Key Features

  1. 1) Dual Registration & Profiles: Freelancers and employers can create verified accounts with portfolio listings and biographies.
  2. 2) Job Publishing & Application Workflow: Post hiring requirements, filter applicants, and submit proposals easily.
  3. 3) Systematic Job Categories & Search: Search jobs with keyword filtering across tech, design, marketing, and writing.
  4. 4) Reviews & Star Ratings: Transparent feedback system allowing employers and contractors to rate project outcomes.
  5. 5) Dynamic Admin Moderation Dashboard: Content verification and job approval mechanisms for platform integrity.
